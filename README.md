# WikiQuiz

> Turn any Wikipedia article into a quiz — instantly.

WikiQuiz is a free, open-source quiz tool that generates questions directly from Wikipedia articles. No AI, no accounts, no paywalls — just pure, sourced knowledge turned into interactive quizzes.

![WikiQuiz Homepage](screenshots/homepage.jpg)

---

## Features

- **Paste any Wikipedia link** — drop a Wikipedia URL and get a quiz in seconds
- **Surprise Me** — get a random Wikipedia article with enough content to quiz on
- **Trending articles** — browse today's most-read Wikipedia articles
- **3 question types** — fill in the blank questions with multiple choice answers
- **Choose your quiz length** — 10, 15, 20, 30, or 50 questions
- **Instant feedback** — answers highlight green or red immediately after selection
- **Article preview** — read the full Wikipedia article before or during the quiz
- **No account needed** — completely free, no sign-up required
- **Mobile friendly** — works on any screen size

## Tech Stack

- **Frontend** — Blade templates, Tailwind CSS, Flowbite
- **Data** — Wikipedia REST API (free, no key required)
- **Deployment** — Vercel

---

## How It Works

1. User pastes a Wikipedia link or picks a trending/random article
2. The app fetches the full article text from the Wikipedia API
3. A client-side algorithm parses sentences and extracts keywords — years, proper nouns, places, roles, numbers
4. Questions are generated by blanking out key terms and sourcing plausible wrong answers from the same article
5. User takes the quiz with immediate right/wrong feedback
6. Results are shown at the end with score and accuracy

No AI is used at any point — every question comes directly from the article content.

## Local Development

### Requirements

- PHP 8.2+
- Composer
- Node.js 18+
- XAMPP or Laravel Herd

### Setup

```bash
# Clone the repository
git clone https://github.com/Sanik0/WikiQuiz.git
cd WikiQuiz

# Install PHP dependencies
composer install

# Install Node dependencies
npm install

# Copy environment file
cp .env.example .env

# Generate app key
php artisan key:generate

# Set session driver (no database needed)
# In .env, set:
# SESSION_DRIVER=file

# Build assets
npm run dev

# Start the server
php artisan serve
```

Visit `http://localhost:8000`

## Deployment

This project is deployed on Vercel using the `vercel-php` community runtime.

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel --prod
```

Make sure to set the following environment variables in your Vercel dashboard:

| Variable | Value |
|---|---|
| `APP_KEY` | your generated app key |
| `APP_ENV` | production |
| `APP_DEBUG` | false |
| `SESSION_DRIVER` | cookie |
| `CACHE_DRIVER` | array |
| `VIEW_COMPILED_PATH` | /tmp/views |

## Wikipedia API

WikiQuiz uses the following Wikipedia API endpoints — all free with no API key:

| Endpoint | Usage |
|---|---|
| `/api/rest_v1/page/html/{title}` | Fetch full article HTML |
| `/api/rest_v1/page/summary/{title}` | Fetch article title and thumbnail |
| `/api/rest_v1/page/random/summary` | Fetch a random article |
| `/w/api.php?action=query&prop=extracts` | Fetch plain text for quiz generation |
| `/api/rest_v1/metrics/pageviews/top/` | Fetch trending articles |
